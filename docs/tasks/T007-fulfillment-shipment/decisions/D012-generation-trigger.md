# D-012 履约单生成时机（建议方案，待用户确认）

## 决策

Worker 自动生成：单 Worker 循环新增第六任务「履约生成」——扫描 `status='success'` 且组内存在 paid 订单但尚无履约单的组，按组为事务批量创建（order_id 唯一约束兜底幂等；任一失败整组回滚，下一轮重试；重启恢复全靠 DB 状态）。

## 备选与理由

- 管理员确认后生成：多一步人工阻塞、漏操作导致用户无进度，且幂等保护仍不可省；需求 §6.5 的履约管理入口是"待拆分发货拼单组"（即生成后待发货），未要求生成确认环节。

## 影响

D010 的"单 Worker 五任务"扩展为六任务（履约生成），循环模式不变；记录于本决策。
