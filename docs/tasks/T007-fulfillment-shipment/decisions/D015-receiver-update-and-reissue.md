# D-015 发货前改址与补发权限（建议方案，待用户确认）

## 决策

- 用户不可改址（沿用订单地址快照不可变原则，T004）。
- 管理员（order:manage）可在履约单**发货前**修改收货快照：覆盖扁平列、`receiver_version` +1、写审计（含新旧版本）；`shipped` 后锁定（RECEIVER_LOCKED）。
- 补发：order:manage + 原因必填 + 审计；追加 is_reissue 包裹；数量 >0；不改变发货进度与守恒。

## 理由

发货前快递面单需最新地址，完全禁止会迫使线下绕过系统；版本化+审计保留可追溯性。未来售后工单可通过公开用例发起改址/补发，本轮不实现工单。
