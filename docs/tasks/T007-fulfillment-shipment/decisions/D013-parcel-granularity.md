# D-013 包裹粒度、部分发货与补发边界

> **状态：已确认**（用户 2026-10-01 通过方案选项确认："全状态可补发+锁地址"）。
> 补发边界（独立审查 R06 后补充，2026-10-01）：
> - 任意状态（含 pending_shipment/completed）可追加补发包裹：关联本履约单、原因必填、写审计；
> - **补发不改变主发货进度与状态**（状态仅由非补发 Σ数量推导）；
> - **地址锁定条件 = 存在任何包裹（含补发）**：有包裹即不可修改收货快照（面单/轨迹依赖原地址）。

## 决策

一履约单**多包裹**：包裹（Shipment）创建即发货（快递公司+运单号+本次数量）。
- 部分发货：Σ非补发包裹数量 < 分配数量 → `partially_shipped`；补足 → `shipped`。
- 补发：追加 `is_reissue=true` 包裹，原因必填、写审计、不计入发货进度（Σ 非补发守恒不受影响）。

## 备选与理由

- 一单一包裹 + 覆盖原运单：丢失补发轨迹，不符需求"单独处理补发"。
