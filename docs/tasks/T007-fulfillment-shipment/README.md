# T007 分份履约与独立发货

- **编号**：T007（唯一；子功能 F026–F030，已核对无冲突：现有子功能至 F025，任务至 T006，迁移至 0015）。
- **目标**：拼单成功后为每位有效参与用户生成独立履约单，按购买份额精确分配商品数量（整数克，守恒可证明）；管理员分别发货（快递公司+运单）、部分发货、补发、导出发货单；用户查看本人履约进度并确认收货。一个用户发货不代表整组完成；履约事实与订单/支付/组状态投影分离。
- **主领域**：Fulfillment（分份履约）；**协作领域**：GroupBuying（成功组事实）、Ordering（有效订单与快照）、IdentityAccess（用户昵称/权限）、Audit（操作审计）。
- **前置**：T004（组/订单/快照）、T006（支付闭环、组成功事实、Worker 模式）。**不实施**：视觉改造、客服、售后工单、看板、物流渠道对接（运单为后台录入）。
- **当前状态**：验证中——2026-10-02 复验收尾 5 项全部处理（十进制换算/零分配拒绝/导出审计阻断/单位文案/D015 三次征询未获答复按推荐推进并标注），专项 38/38、全量 210/210；待独立复验关闭。D011–D014 已于同日经用户选项确认（来源：AskUserQuestion 四问四答）；D015 仍为建议方案未确认。修复与回归见 verification.md 第四轮与 [independent-acceptance.md](independent-acceptance.md)。
- **阻塞项**：D015（改址规则）未经用户确认（按建议方案推进，已实现并验收）；真实微信/真机未验；独立复验通过前不标记任务完成。
