# 本地微信模拟联调规范

依据：用户 2026-10-02 授权四阶段连续执行；保留 D015/D019/D020/D021。范围：本地真实后端、真实 PG 和 Worker，微信使用隔离模拟；非目标：T005、真实付款、订阅消息外发、体验版上传与公网部署。

## AC1 环境配置与隔离

增加 APP_ENV=local|simulation|production（默认 local）；微信端点覆盖仅本地/模拟可用，生产必须拒绝。API/Worker 同步收到渠道变量，密钥只读挂载。独立 Compose 项目、卷、数据库、媒体目录；模拟控制面只绑定本机。

Given 独立环境已就绪，When 执行本功能，Then 满足上述行为及 TDD：生产拒绝模拟端点与缺配置；Compose 变量传递与隔离冒烟。。

## AC2 登录与手机号模拟

复用 /sns/jscode2session、/cgi-bin/stable_token、/wxa/business/getuserphonenumber 的既有装置契约；固定 alice/bob/charlie 测试身份，模拟凭证与真实凭证隔离。既有 /api/mini/v1/auth/login 和 /auth/phone 不变。拒绝/失效/故障不得创建或修改身份事实。

Given 独立环境已就绪，When 执行本功能，Then 满足上述行为及 TDD：成功登录、凭证重放/失效、手机号拒绝及渠道失败；生产 HTTP 适配器对本地服务联调。。

## AC3 支付退款模拟

复用 v3 下单/查单/关单/退款契约；金额分、商户订单号与退款号保留。控制面设置渠道状态后发送 RSA 签名、AES-GCM 加密回调；可重放与故障注入。不得直接写业务数据库；站内通知保留 D021。

Given 独立环境已就绪，When 执行本功能，Then 满足上述行为及 TDD：查单、签名、密文、处理中/失败/成功退款、重复及迟到回调；真实 API/PG 集成。。


## 契约与页面

业务 API 复用 T003/T004/T006/T007/T008/T009 spec：Bearer 认证、后台权限、ApiResponse 包络、分页、整数分、ISO 时间、幂等规则不变。新增内容仅本地装置/配置/脚本。小程序与后台保留正常/加载/空数据/失败/权限状态；页面逻辑测试不等同微信渲染。模拟控制面具体字段与失败契约在对应子功能 spec 定义后实现。

## 验收

AC4：专项→全量→隔离整体冒烟均通过，无失败无跳过。AC5：每个功能有中文提交和 verification，保留其他未提交文件；真实渠道与真机单列待验。

异常：装置/进程失败退出非零，清理只限本任务创建资源；保留诊断但不打印密钥。涉及业务缺陷先修订 DDD/spec/plan，再回归测试先红后绿。
