# D022 客服超时提醒（D018 的通知阶段决策）

- **状态**：用户已确认（2026-10-02，AskUserQuestion，选「站内提醒主管（推荐）」）。取代 T008 D018「第一版不做超时提醒」的旧建议状态。
- **决策**：Worker 定时扫描「进行中（queued/active）、超过阈值未获客服可见回复」的会话，按「会话×主管」幂等生成 `cs.conversation.timeout` 站内提醒通知。阈值 `CS_FIRST_RESPONSE_TIMEOUT_MINUTES` 默认 15 分钟可配。提醒对象=心跳 60 秒内的在线 `cs_supervisor`；无在线主管时落给全部 active 主管留痕。**不**自动转派、**不**改 T008 分配逻辑。
- **理由**：落实需求 §5「超过设定时间未回复时提醒客服主管」；为通知管道提供真实业务事件；避免触碰已验收的会话分配领域（影响面最大的「提醒+自动升级」被排除）。
- **边界**：「客服可见回复」= `cs_messages.sender='agent' AND internal=false`（内部备注不算回复）；已首响会话不再进入扫描结果。
