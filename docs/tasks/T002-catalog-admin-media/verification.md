## 浏览器实操记录（管理员全流程）

1. 打开 http://127.0.0.1:8080 → 未登录显示登录页；错误密码提示"用户名或密码不正确"。
2. 正确凭据登录 → 进入商品与库存（空态正确显示"暂无商品"）。
3. 新建商品：填写名称/介绍/原价 500/数量 10/单位斤/初始库存 8；页面实时预览整件参考价 ¥505.00 与四档份额参考价（¥252.50/¥168.33/¥126.25/¥101.00）。
4. 图片上传：通过表单上传组件驱动真实上传（页面内生成 640×480 PNG 经 input change 事件走真实 multipart API）；主图预览立即显示。
5. 创建草稿 → 跳转编辑页，库存 8 件、首条变动"创建商品初始化库存 +8"。
6. 上架成功；库存调整 -2 件（原因必填）→ 当前可售 6 件，变动记录两条留痕。
7. 商品列表：主图缩略、价格、库存、状态徽标、分页正确；截图 `artifacts/admin-product-list.png`。
8. 图片库：元数据（PNG 640×480 300KB）、"被 1 个商品引用"徽标、删除按钮禁用（被引用不可删）；截图 `artifacts/admin-media-library.png`。

## 未覆盖与边界

- **微信开发者工具/真机未验证**：小程序通过 TypeScript 类型检查、页面注册测试和真实接口（curl）验证；AppID 为 touristappid，未在开发者工具编译、真机预览或验证图片实际渲染。AC08 的平台侧运行需用户环境补充验证。

- 管理后台为本地 HTTP（8080/5173），正式部署需 HTTPS、真实域名与微信合法域名配置。
- 金额/份额支付报价、尾差分摊、库存预留等仍为后续交易任务决策项（见 spec 待决策表），本任务展示价均标注"参考"。
