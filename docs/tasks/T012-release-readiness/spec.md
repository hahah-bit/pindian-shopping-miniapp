# 部署与运行维护准备规范

依据：用户 2026-10-02 授权四阶段连续执行；保留 D015/D019/D020/D021。范围：本地真实后端、真实 PG 和 Worker，微信使用隔离模拟；非目标：T005、真实付款、订阅消息外发、体验版上传与公网部署。

## AC1 生产部署配置

增加生产 Compose、HTTPS 代理模板、只读密钥与运行配置预检。API/Worker 不开放公网端口，数据库仅内网，admin 经 HTTPS；缺少凭据或模拟端点时生产预检失败。保留本地默认启动。

Given 独立环境已就绪，When 执行本功能，Then 满足上述行为及 配置隔离采用 TDD；装配后在本地隔离环境生成临时 TLS、构建并验证 HTTPS/健康/路由。。

## AC2 备份恢复与健康检查

备份 PG 与媒体生成清单及校验摘要，恢复仅指定隔离目标，禁止覆盖当前源项目；备份前暂停 API/Worker 写入，结束恢复原运行状态。核对业务数据与媒体哈希；检查 API/Worker/PG。不记录密钥或连接密码。

Given 独立环境已就绪，When 执行本功能，Then 满足上述行为及 目标隔离与恢复前校验采用 TDD；真实备份→新隔离项目恢复→核对事实与媒体，不能以文件存在代替恢复。。

## AC3 发布演练与交接

提供版本化部署包、迁移/发布/回退说明。回退需明确 schema 兼容；不兼容时从备份恢复到独立项目再切换，不原地盲目降级。本地实际部署/重启/恢复演练；提供真实微信、真机、体验版待验清单。

Given 独立环境已就绪，When 执行本功能，Then 满足上述行为及 发布目标和版本约束采用 TDD；装配后本地演练发布、重启、恢复。真实审核/到账/触达不计入本轮通过。。


## 契约与页面

业务 API 复用 T003/T004/T006/T007/T008/T009 spec：Bearer 认证、后台权限、ApiResponse 包络、分页、整数分、ISO 时间、幂等规则不变。新增内容仅本地装置/配置/脚本。小程序与后台保留正常/加载/空数据/失败/权限状态；页面逻辑测试不等同微信渲染。模拟控制面具体字段与失败契约在对应子功能 spec 定义后实现。

## 验收

AC4：专项→全量→隔离整体冒烟均通过，无失败无跳过。AC5：每个功能有中文提交和 verification，保留其他未提交文件；真实渠道与真机单列待验。

异常：装置/进程失败退出非零，清理只限本任务创建资源；保留诊断但不打印密钥。涉及业务缺陷先修订 DDD/spec/plan，再回归测试先红后绿。
