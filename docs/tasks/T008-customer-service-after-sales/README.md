# T008 自建实时客服与售后工单

- **编号**：T008（唯一；现有功能至 F030、任务至 T007、迁移至 0017）；子功能 F031–F036。
- **目标**：自建客服系统——用户发送文字/图片/商品/订单/拼单/退款卡片，客服后台接入/回复/转接/备注/转工单；新会话入公共队列自动分配在线客服；离线自动转留言；历史分页与断线补取；售后工单受理/处理/解决/关闭，可经公开用例协调退款/补发。第一版不含语音/视频/文件/AI 回复。
- **负责 Agent**：Codex；本次修改目录：后端客服/售后/身份/支付/履约、两端feature、契约、测试和本轮任务文档（详细索引见整改plan）。
- **主领域**：CustomerService（会话与消息）、AfterSales（工单）；协作：IdentityAccess（用户/客服身份）、Catalog/Ordering/GroupBuying/Payments（卡片只读投影）、Audit。
- **前置**：T003（用户身份）、T006（退款事实）、T007（履约事实）。
- **当前状态**：已完成（本轮授权整改及本地验收）；专项36/36、全量249/249零跳过、隔离Docker及有数据后台操作通过，真实渠道/微信工具/真机待发布环境验证。详见 [整改最终验证](remediation-verification.md)。
- **阻塞项**：本轮代码整改无待决策阻塞；D020明确取代D017不增加审批层建议。D018超时提醒/升级尚未确认，转入后续通知设计，不能声称整个MVP完成。
