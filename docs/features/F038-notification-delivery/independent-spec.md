# F038 独立审查补充规范

复用原spec与T009 A4/A5/A6；已确认业务规则不变。

- R01 Given 投递插入失败，When 创建通知，Then 通知和投递均回滚；幂等重试能完整重建。
- R02 Given 首实例持有有效租约，When 第二实例扫描，Then 不得再认领；到期可恢复，旧token保存不覆盖新实例结果。
- R03 Given 超时会话超过批次上限且旧会话已提醒，When 再扫描，Then 继续提醒后续会话；主管变更仍可补建缺失接收者。
- R04 Given 审计落库失败，When 手工重试，Then 投递重置也回滚；正在认领的 failed 不允许重试。

新增迁移0028仅增加lease字段，不改写历史事实。既有HTTP响应不增加内部lease字段。
