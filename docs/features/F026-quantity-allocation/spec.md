# F026-quantity-allocation spec

> 补充说明：本文件于 2026-10-01 独立审查后补齐，记录**既已实现**的行为与规则（非先于实现的设计）；总契约见 T007 spec.md。

输入整件最小单位数与订单份额列表（Σ=60），floor 分配+前序补 1；输出保持输入顺序；非法输入（非正/非整数/空/Σ≠60）VALIDATION_FAILED。单位注册表：重量（斤=500g/千克=1000/克=1/两=50，小数允许但换算须整数克）、计数（整件）、未知单位 null。

## D019 整改修订

复用T007 [D019](../../tasks/T007-fulfillment-shipment/decisions/D019-positive-allocation.md)，不改原floor+创建顺序补差。任意允许有序满额组合产生零分配时拒绝上架/下单；历史组暂停并保留快照，按F036审核全额退款。生成在组锁内查退款停止记录，保留所有原订单的分配后跳过停止订单，不向他人重分历史数量。
