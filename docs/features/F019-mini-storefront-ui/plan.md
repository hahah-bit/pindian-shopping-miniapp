# F019 实施与验证计划

依赖 [spec](spec.md)、[DDD](ddd.md) 与 [T013 plan](../../tasks/T013-mini-experience-refresh/plan.md)。原生小程序+TypeScript保持，不引入网页框架或GSAP。

1. 布局/主题不用TDD：全局语义色、按钮触摸反馈、灰白背景、两列商品大图、搜索及分类、用户页和表单；使用实际API和原生swiper。
2. 下单缺陷采用回归TDD：实际详情页面点击必须提交当前商品ID并到达真实订单详情；已有支付语义不变。
3. 搜索采用请求版本防迟到覆盖，分页同筛选；轮播进入/隐藏/弹层状态管理，原生预览、系统导航、安全区。
4. 原创一致线性Tab图标，transform/opacity反馈120–320ms，切换220ms，轮播420ms/4500ms；CSS减少动效媒体查询保留，平台实际支持待真机。
5. Node装置加载实际页面逻辑并访问独立本地API，覆盖下单、搜索竞态、分页失败恢复、未登录页面；布局另用开发者工具原生截图与交互，不能用逻辑测试代替。
6. F050/F051接各自接口后，本任务专项通过再全量；具体命令 npm run test:task:t013、npm test。Impeccable独立视觉审查/设计文档接在最终修正后；精确暂存并中文提交。

权限、金额、数量和库存均由现有后端权威决定。历史T005目录保留作原规划材料，新方向与验收以T013为准。
