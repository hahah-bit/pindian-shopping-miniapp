# F019 DDD

复用 [T005 DDD](../../tasks/T005-mini-ui-redesign/ddd.md) 中的领域认领、统一语言、UML、读模型与事务边界；本功能无领域变更。

页面组件是渲染与输入适配，不是聚合或业务服务。基础组件放在小程序展示层，商品字段映射归 Catalog 页面，用户资料与地址字段映射归对应 feature。共享展示组件不能调用他域内部实现，也不能计算支付金额、创造拼单状态或绕过地址权限。

状态细化：商品正常/瀑布流图片尺寸准备/骨架/空/失败/404/售罄/坏图；个人中心未登录/加载/已登录/资料提交/失败/过期；地址无权限/加载/空/正常/保存/失败；订单列表/详情沿用 T004 的真实状态与权限，微信支付尚未开放。表单 busy/loading 状态沿用现有规则，防止 UI 改造丢失重复点击保护。

首页的两列等宽瀑布流是纯视图布局，图片尺寸与列高度只用于排版，不能影响商品价格、库存或下单规则。商品已显示后固定列位置；翻页追加时不重新搬动旧卡片；刷新开启新的视图排布周期。布局不要求新增领域事件、事务或后端尺寸元数据。
