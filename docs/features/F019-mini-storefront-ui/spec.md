# F019 spec

目标、范围、七个页面设计及接口契约复用 [T005 spec](../../tasks/T005-mini-ui-redesign/spec.md)，完整覆盖 AC01–AC08、AC10–AC11。历史 T005 为规划；本轮 T013 已明确授权实施；首页已按2026-10-01用户要求确定为双列等宽、卡片高度错落的瀑布流。

补充约束：基础组件封装只暴露展示属性和事件，商品、资料、地址页面调用原有请求适配器。区域 picker 与微信原生登录/手机号能力的绑定需逐项验证，不能因替换组件造成授权事件丢失。分页、图片异常、未登录与提交中的 UI 状态保留。

输入输出：组件输入为现有视图模型、加载状态、图片排版比例与错误信息；输出为原有刷新、导航、编辑、授权、保存、下单和取消等用户动作。保留T004已有事件，不新增支付行为或修改交易规则。瀑布流按真实图片比例和内容排版，未知尺寸使用固定占位；后续图片加载或翻页不得搬动旧卡片。

验收复用 T005 AC01–AC08、AC10–AC11；所有关键业务字段、失败反馈和权限流程不能只靠截图验证。Mock 截图作为视觉预览，真实接口及真实微信验证分开记录。
