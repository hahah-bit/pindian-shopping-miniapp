# Pi 智能客服规范

## T014导航修订（实现前）

采用原生客服Tab；原客服/个人入口switchTab直达聊天，人工与售后navigateTo原中心。再进入Tab重新确认本人；退出或换用户清消息/草稿，旧发送/历史回调不得影响新用户。发送中同身份再进入保留pending，不重复发起模型请求。对应T014 AC01/02/05；接口与权限复用下文。

## 分页与租约细化（实现前）

同身份返回保留内存中未落库的失败消息，服务端相同clientMessageId的记录优先；不写入本地磁盘缓存，换身份立即清理。旧历史、分页和发送回调均按身份及请求版本隔离。

GET before 改为本人的轮次 UUID 游标，按 (createdAt,id) 排序，避免同毫秒分页丢失；不返回他人的游标存在性。GET 返回 items、nextBefore。单用户会话行短事务锁串行认领，数据库窗口60秒最多10次尝试（含重试）；45秒租约阻止并行，超过租约后旧执行只能凭 leaseId 条件完成，不能覆盖新尝试。失败状态对用户保留轮次，可同键重试，不自动重复写请求。上下文只带最近完成的本人轮次，手机号在模型传输前脱敏。模型 key/base/model 未配置时503，客户端仍能进入人工客服。

依据：2026-10-06 用户开发授权；覆盖 [T013 spec](../../tasks/T013-mini-experience-refresh/spec.md) AC05/06。

智能会话按 userId 归属，AiTurn 记录文本、回复、状态、clientMessageId、租约。应用用例仅能读写本人智能轮次；Pi 出站适配空 tools；无业务写工具。

迁移0030增加独立轮次表及唯一键/用户索引；认领与完成短事务，模型 HTTP 不持有事务。默认30秒模型超时、租约45秒、每分钟10次、最近20条/8000字符，失败可同键重试；新 Agent 每次请求重建本人上下文。GET before 本人轮次UUID/pageSize20最多50；POST UUID/text≤1000，401/400/409/429/502/503/504准确；空模型配置保留人工客服正常。

正常/加载/空/失败/过期状态均与真实契约一致。金额仍整数分、原业务规则不变。验收 Given本人授权且输入有效，When完成主要操作，Then结果满足上述不变量；Given网络失败、无权限或重复请求，When重试/取消，Then不越权、不丢失历史或重复副作用。完整编号验收引用 T013 AC05/06，不把模拟平台写成真机验证。
