# 发布演练与交接 DDD

复用 [大任务模型与 UML](../../tasks/T012-release-readiness/ddd.md)。无新增业务聚合；提供版本化部署包、迁移/发布/回退说明。回退需明确 schema 兼容；不兼容时从备份恢复到独立项目再切换，不原地盲目降级。本地实际部署/重启/恢复演练；提供真实微信、真机、体验版待验清单。

统一语言、状态、事务及跨域边界沿用大任务；装置不得越过领域校验。实际交易/金额/数量/权限事实仍由既有聚合和用例控制。
