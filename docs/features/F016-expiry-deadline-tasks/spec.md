# F016 spec

上游：[T004 spec](../../tasks/T004-group-order-reservation/spec.md) G8/G9、AC04。

## 验收条件

- AC-F16-1 过期预占被任务释放（容量回落、订单 expired）；未到期不动。
- AC-F16-2 任务重复执行不重复释放（状态条件幂等）。
- AC-F16-3 "重启恢复"：任务无内存状态，进程重启后下一轮扫描继续处理。
- AC-F16-4 组截止：组 failed + 库存释放 + 残留预占/订单过期；重复执行幂等。
- AC-F16-5 过期后的支付生效（内部用例）被拒（G9）。
- AC-F16-6 任务异常不中断循环，记录后下轮重试。
