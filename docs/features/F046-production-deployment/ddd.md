# 生产部署配置 DDD

复用 [大任务模型与 UML](../../tasks/T012-release-readiness/ddd.md)。无新增业务聚合；增加生产 Compose、HTTPS 代理模板、只读密钥与运行配置预检。API/Worker 不开放公网端口，数据库仅内网，admin 经 HTTPS；缺少凭据或模拟端点时生产预检失败。保留本地默认启动。

统一语言、状态、事务及跨域边界沿用大任务；装置不得越过领域校验。实际交易/金额/数量/权限事实仍由既有聚合和用例控制。


## T013复验发现的临时TLS续建修订（2026-10-06，实现前）
复用运行维护模型，无业务领域变更；演练临时证书是本地运维资产，只有data/release/tls中的证书可自动重建，生产凭据和证书不操作。

同次复验发现：初始化构建独立working镜像，却将演练env写成不存在的封存镜像标签，恢复实际失败。生成env须直接引用rehearsalImageTags输出；保留封存镜像不可覆盖约束，实际隔离恢复验证。
