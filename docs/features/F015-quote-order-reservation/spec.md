# F015 spec

上游：[T004 spec](../../tasks/T004-group-order-reservation/spec.md) G4/G6/G7/G10/G11/G14/G15、AC03/AC05。

## 验收条件

- AC-F15-1 尾差矩阵：P=50000 的 1/3×3（16833/16833/16834）、1/2+1/2（无尾差）、混合组合；商品/服务费分别守恒（G10）。
- AC-F15-2 幂等：同键同内容返回原单（不新增预占）；同键异内容 409 IDEMPOTENCY_CONFLICT（G6）。
- AC-F15-3 竞争：两人同买最后份额 → 一人成功（补差）+ 另一人重试建新组或 409（G4）；重试上限 3 次（G15）。
- AC-F15-4 回滚：注入失败时订单/预占/组/库存四者无残留（G7）。
- AC-F15-5 地址归属：他人地址 404；快照不随后续修改变化（G11）。
- AC-F15-6 下架商品拒绝新预占（PRODUCT_NOT_ON_SHELF）；组快照报价不受改价影响（G13）。
- AC-F15-7 金额字段全部服务端计算；请求体无金额字段（G14）。
- AC-F15-8 预占 15 分钟（可配）；订单号唯一格式 PO+日期+随机。
