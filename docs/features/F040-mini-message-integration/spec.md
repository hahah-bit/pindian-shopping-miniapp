# F040 Spec

引用 [T009 spec](../../tasks/T009-dashboard-notification-audit/spec.md) §3.2/§3.3/§5、验收 A1–A8/A10；补充细节：

## 页面

- `/access`：操作日志表（时间/管理员/动作/资源/详情摘要）+ 筛选（动作、资源类型、管理员ID、起止日期）+ 分页 + 角色权限矩阵区；无权限显示 403 提示。
- `/notifications`：投递表（事件/接收者/渠道/状态徽标/尝试次数/下次重试/错误）+ 状态与事件筛选 + 分页；failed 行「重试」按钮（确认→调用→刷新），skipped 行按钮禁用（title 说明原因）。
- 小程序消息中心：我的页入口+未读徽标；列表（标题/正文/时间/未读圆点）+ 分页加载更多 + 点击置已读；未登录引导；空态/失败重试。

## 集成测试范围（integration-db-http.test.mjs）

真实 PG + 生产装配 HTTP：种子全业务事实，验证：

1. 看板两端点逐指标断言 + 日期参数 + 空基准日；
2. 权限矩阵（超管/客服主管/客服/商品管理员/未认证）；
3. 退款成功事实 → 事件补抓 → 消息中心可见 + 未读数 + 已读幂等 + 他人 404；
4. 投递 skipped 留痕 + 手工重试 409 + 审计落库；
5. 超时提醒生成/不生成/幂等（阈值注入）；
6. 审计查询筛选+脱敏；
7. 客服资金权限断言抽查。

- spec A1–A8 端到端全部通过；A10 未验项如实记录。
