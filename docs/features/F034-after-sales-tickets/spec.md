# 售后工单及业务协调 规格

依据：[整体 spec](../../tasks/T008-customer-service-after-sales/spec.md)，[整改 spec](../../tasks/T008-customer-service-after-sales/remediation.md)。

范围：RC05–RC07。用户本人校验与客服分配校验必须在后端成立；非授权资源 404，字段校验 400，状态或幂等冲突 409。失败不留下半条业务事实；金额整数分，时间 ISO-8601，页面包括加载、空态、失败、权限和正常状态。

契约、场景和 Given/When/Then 继承上述 spec。退款/补发执行按已确认D020及F036审批流程，客服不能直接执行。当前不包含语音、视频、文件、AI。

处理动作重试规则：clientActionId 为工单、身份类别、身份 ID 范围内的客户端键，1–64 字；同键同动作同内容只记一次 action 和审计，同键异内容 409。事务内先锁工单再查重。受理没有客户端键时，原受理人重复操作返回现状；其他客服不能抢占。前端响应丢失后复用原动作键和内容，禁止以新键掩盖未确认结果。
