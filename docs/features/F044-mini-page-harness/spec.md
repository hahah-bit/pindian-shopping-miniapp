# 小程序页面交互测试 spec

依据：[大任务规范](../../tasks/T011-local-business-acceptance/spec.md)；用户授权本地/模拟范围。

Node 装置编译并加载实际 TS 页面，以 Page/setData/wx 适配驱动生命周期与点击；HTTP 请求真实本地后端。wx 登录/支付来自模拟渠道；wx 成功回调不能直接判订单已支付。验证权限、加载、空态、失败、取消、刷新和消息已读。

验收：不采用 TDD（测试装置/页面装配），实现后冒烟实际页面；微信渲染与真机单列待验。 失败保持明确错误与未完成；既有公共 API、权限与金额单位不变。待决策：无本地实现阻塞；真实环境单列待验。
